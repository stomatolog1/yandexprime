PC INSTALLER USB
================

Структура:
  START.cmd
  Install.ps1
  SDIO\              <- положи сюда SDIO.exe
  GPU\NVIDIA\        <- положи сюда NVIDIA installer .exe
  GPU\AMD\           <- положи сюда AMD installer .exe
  Yandex\            <- сюда можно положить полный/offline Yandex installer
  Logs\              <- сюда пишутся логи

Использование:
1. После установки Windows 11 вставь флешку.
2. Запусти START.cmd.
3. Подтверди UAC.
4. SDIO запустится сразу.
5. Видеокарта определяется автоматически.
6. Запускается соответствующий NVIDIA/AMD установщик.
7. Яндекс устанавливается после готовности установщика.

ВАЖНО ПРО ЯНДЕКС:
- Самый надежный вариант для сборочного места: заранее положить ПОЛНЫЙ
  установщик Яндекс Браузера в Yandex\.
- Скрипт также поддерживает фоновую загрузку через BITS: для этого открой
  Install.ps1 и укажи официальный URL в переменной $YANDEX_URL.
- Не используй случайные зеркала; бери установщик с официального сайта Яндекса.

ВАЖНО ПРО ДРАЙВЕРЫ:
- Скрипт берет первый .exe из соответствующей папки.
- Если в папке несколько EXE, лучше оставить только нужный установщик.
- Для NVIDIA и AMD используй заранее проверенные тобой пакеты.

UAC:
Windows 11 не разрешает надежный автоматический Autorun .exe с USB.
Поэтому START.cmd запускается вручную одним двойным кликом и сам поднимает
PowerShell с правами администратора.

Если хочешь полностью автоматический "тихий" режим установки драйверов,
сначала проверь ключи silent-install именно для тех версий драйверов,
которые используются у вас.


УДАЛЕНИЕ ЯРЛЫКОВ INTERNET EXPLORER:
После установки GPU скрипт ищет ярлыки .lnk на рабочем столе,
в меню Пуск и в известных папках быстрого запуска. Удаляются только
ярлыки, у которых TargetPath указывает на iexplore.exe.
Microsoft Edge и сам Windows при этом не удаляются.
